# Codenames Telegram Mini App

Monorepo scaffold for the Codenames Telegram Mini App MVP.

## Repository Layout

- `client/` - React frontend
- `server/` - future Express backend
- `shared/` - shared code for both applications
- `docs/` - project documentation
- `.github/` - repository instructions and workflows

## Client

The client is a Vite React + TypeScript app with Tailwind CSS v4.

### Commands

- `npm install`
- `npm run dev`
- `npm run build`
